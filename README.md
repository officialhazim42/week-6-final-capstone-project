# Student Portfolio & Project Showcase

## Week 6 – Final Capstone Project

The **Student Portfolio & Project Showcase** is my final capstone project developed during Week 6 of my internship.

This project brings together the skills developed throughout the internship, including HTML, CSS, JavaScript, responsive design, project planning, testing, debugging, optimization, Git/GitHub workflow, documentation, and deployment readiness.

## 🚀 How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in a modern web browser.
4. Navigate through the sections using the menu.
5. Test the responsive layout by resizing the browser window.
6. Test the contact form with valid information.

No backend or database is required.
